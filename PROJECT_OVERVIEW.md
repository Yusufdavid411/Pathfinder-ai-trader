# Project Overview

PathFinder AI Trader is planned as a modular trading platform with mobile, desktop, web, backend, learning, and broker-facing components.

## Product Vision

PAT will eventually support:

- Flutter mobile and desktop clients.
- React + Vite web dashboard.
- Python AI Engine.
- Firebase backend services.
- IQ Option integration.
- Learning Engine.
- Shadow Trading.
- Market Quality Engine.
- Risk Management.
- AI Coach.
- Multi-broker support.

## Foundation Scope

This foundation creates only the structural base. It defines where future capabilities will live, how boundaries are separated, and how tooling will be organized.

Out of scope for this stage:

- Trading signals.
- Strategy execution.
- AI inference.
- AI training.
- Broker authentication.
- Broker order placement.
- Market data ingestion.
- Firebase initialization.
