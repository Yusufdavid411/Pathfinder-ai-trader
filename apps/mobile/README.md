# PAT Mobile

Flutter application shell for PathFinder AI Trader.

## Scope

This app contains navigation, dependency placeholders, feature folders, and placeholder screens only.

No trading logic, AI logic, broker integration, or Firebase integration is implemented in this stage.

## Structure

- `lib/core` - app-level routing and core wiring.
- `lib/features` - feature-first modules.
- `lib/shared` - shared mobile-only primitives.
- `lib/services` - future app service clients.
- `lib/widgets` - reusable UI widgets.
- `lib/theme` - app theme definitions.
- `lib/config` - app configuration placeholders.

## Setup

Install Flutter stable, then run:

```bash
flutter pub get
flutter run
```
