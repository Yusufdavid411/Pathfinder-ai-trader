# Pathfinder AI Trader

Pathfinder is being built as a safety-first trading analysis system. The first
implemented component is a **read-only IQ Option traderoom market-data reader**.
It displays conservatively parsed public page values in a local debug panel; it
does not trade and is not connected to an AI decision engine.

See [the V1 reader guide](docs/iq-option-market-data-reader-v1.md) for its
architecture, privacy boundary, installation, and testing instructions.
